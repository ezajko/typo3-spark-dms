============
Introduction
============

What is Spark DMS?
==================

Spark DMS (Document Management System) is a TYPO3 extension that provides 
comprehensive document management capabilities for your website. It enables 
you to organize, categorize, and publish documents with full version control.

Key Features
============

Document Management
-------------------

- **Document Records**: Store documents with metadata including title, 
  registry number, date, and protection status
- **Versioning**: Maintain multiple versions of each document with automatic 
  tracking of changes
- **File Attachments**: Attach files (PDF, Word, etc.) to document versions
- **Related Documents**: Link documents to each other for cross-referencing

Organization
------------

- **Document Types**: Classify documents by type (e.g., Regulation, Report, Form)
- **Categories**: Organize documents in hierarchical categories
- **Protected Documents**: Mark documents as protected (login required)

Frontend Display
----------------

- **Multiple View Types**: Choose from Default, List, Card, Simple, Folder, 
  or Debug views
- **Pagination**: Built-in pagination with configurable items per page
- **Frontend Filtering**: Optional filter form for end-users to search and 
  filter documents
- **Detail Pages**: Individual document pages with version history

Backend Management
------------------

- **Backend Module**: Dedicated module for document management with filtering 
  and sorting
- **FlexForm Configuration**: Easy configuration through content element settings
- **Pretty URLs**: Automatic URL routing for clean document URLs

CLI Commands
------------

- **dms:import**: Import documents and add versions via command line
- **dms:list**: List documents with filtering and export options
- **dms:export**: Export documents to CSV or JSON
- **Bulk Import**: Script for importing from CSV files
